Glossary

TermMeaning
AgentAn AI receptionist or assistant that talks with your customers on the Newo platform
Agent CreatorThe tool for creating a new agent in a few steps
BuilderNewo's full editor for flows, skills and settings
Customer PortalWhere businesses manage agent settings, billing, call history and reports
DTMFTouch-tone keypad input during a call
FlowA conversation path the agent follows
IntegrationA connection between the agent and a business system
PAYGPay as you go: a plan billed only for usage
Partner PortalWhere white-label partners manage customers, products and quotas
QuotaA usage limit a partner sets for a customer or agent
SIPThe standard protocol phone systems use to connect calls over the internet
SkillA single action an agent can take
Speech-to-speechA model that hears the caller and answers in speech directly
Speed DialThe setup checklist that takes a new agent to launch
SuperAgentNewo's standard, ready-made agent
UnitThe measure of agent usage that billing is based on
Vibe ModeSetting up and changing an agent by chatting with it
Voice connectorAn agent's voice settings: speech recognition, voice and mode
WebhookAn automatic message the Newo platform sends to your system when something happens
White-labelReselling the Newo platform under a partner's own brand
